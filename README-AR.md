# الحسن للاتصالات — مشروع تأسيسي جديد

هذا المشروع يحتوي على واجهة متجر عربية متوافقة مع الهاتف وصفحة إدارة محلية للمعاينة.

## الملفات
- `index.html` واجهة المتجر.
- `styles.css` التصميم الأسود والذهبي، مع وضع فاتح/داكن.
- `app.js` البحث والأقسام والسلة ورسائل واتساب.
- `admin.html` نموذج أولي لإدارة المنتجات ونسخها احتياطيًا في المتصفح.

## مهم قبل النشر العام
هذه النسخة **ليست بعد متجرًا إنتاجيًا كاملًا**: لوحة الإدارة تحفظ المنتجات في `localStorage` على الجهاز/المتصفح الحالي فقط. لا توجد بعد قاعدة بيانات سحابية أو مصادقة مالك أو رفع صور دائم أو صلاحيات مشرف أو تقارير فعلية. لا تضع أسرارًا أو كلمات مرور في هذه الملفات، ولا تعتمد عليها لإدارة مخزون حقيقي قبل ربطها بخلفية آمنة.

## تجربة سريعة
افتح `index.html` في المتصفح. افتح `admin.html` لتجربة إضافة منتج وتنزيل نسخة JSON. المنتجات والأسعار الظاهرة تجريبية وليست أسعار المحل الحقيقية.

## خطوات الإكمال الآمن المطلوبة للنشر
1. إنشاء مستودع GitHub جديد ورفع هذه الملفات.
2. نشر الواجهة على استضافة HTTPS مثل Cloudflare Pages أو Netlify.
3. إنشاء مشروع Supabase (أو خدمة خلفية مماثلة) لقاعدة البيانات والمصادقة وتخزين الصور.
4. إنشاء حساب المالك من لوحة مزود المصادقة والتحقق من البريد؛ لا تُضمّن كلمة المرور في المشروع.
5. إعداد سياسات صلاحيات تمنع الزوار من تعديل المنتجات، وتسمح للمالك/المشرف فقط بذلك.
6. إضافة مخطط قاعدة بيانات وجداول للمنتجات والأقسام والعروض والطلبات والمراجعات والإحصائيات، ثم ربط الواجهة بها.
7. اختبار تسجيل الدخول وتغيير كلمة المرور والنسخ الاحتياطي والرفع قبل إعلان الموقع.
